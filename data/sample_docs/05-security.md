# Information Security Policy

Security is everyone's job. These rules apply to every employee, contractor and intern.

## Accounts and passwords

Use the company password manager for every work account and generate a unique password for each
one. Multi-factor authentication with a hardware security key is required for email, source code
hosting and the cloud console.

## Devices

Company laptops must have full-disk encryption turned on and must lock the screen after five
minutes of inactivity. Install operating system updates within seven days of release. Customer data
must never be stored on personal devices.

## Data classification

All data falls into one of four classes:

- **Public:** information that is already published, such as the marketing website.
- **Internal:** day-to-day documents that are fine to share inside the company.
- **Confidential:** customer data, contracts and financial results. Share only with people who need
  it for their work.
- **Restricted:** credentials, encryption keys and security reports. Access is logged and reviewed
  every quarter.

## Reporting incidents

If you receive a suspicious email, report it to the security team within one hour using the
"Report phishing" button. If you think your laptop or an account has been compromised, disconnect
from the network and contact the security on-call engineer immediately. You will never be blamed
for reporting a mistake quickly.
